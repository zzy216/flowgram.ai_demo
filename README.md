# 审批流程设计器

基于 FlowGram 固定布局实现的中文审批流程配置演示。

## 运行

```bash
npm install
npm run dev
```

开发服务器默认端口被占用时，Rsbuild 会选择可用端口。也可以指定端口：

```bash
npm exec rsbuild -- dev --port 3100 --host 127.0.0.1
```

## 使用

- 点击连接线上的「＋」，添加审批人或条件分支；分支内可以继续添加审批节点和嵌套分支。
- 点击审批卡片，设置审批人类型、人员或岗位、发起人自选、或签/会签、操作权限、回退后的提交路径及抄送。表单权限和扩展标识分别在对应页签配置。
- 点击条件卡片，设置名称、优先级和条件。组内条件为「且」，条件组之间为「或」；支持工程名称、申请金额、发起人部门和发起人条件。
- 点击「添加条件」新增分支；默认分支始终在最后。至少保留一条条件分支和一条默认分支。
- 抽屉内「提交」将配置更新至画布；「重置」恢复打开抽屉时的配置，关闭抽屉放弃尚未提交的修改。
- 「保存流程」校验并保存到当前浏览器的 localStorage，刷新后自动恢复。未完成配置的节点会显示「请设置」，并阻止保存。
- 支持撤销、重做、缩放、适应画布和 JSON 导出。JSON 包含全部节点配置及分支顺序，可作为后续后端接口的数据输入。

人员、岗位、工程和部门均为本地演示选项。当前实现为流程设计器，没有接入组织目录、后端存储、实际审批执行或电子签章服务；表单权限等配置以节点数据形式保存，供执行端后续消费。

## 验证

```bash
npm test
npm run ts-check
npm run lint
npm run build
```

单元测试覆盖审批人必填、发起人自选、条件组 AND/OR 摘要、金额校验、分支排序和本地数据恢复边界。

浏览器已验证：审批人校验及配置提交、表单权限、扩展标识、操作权限与抄送、条件组编辑、分支内新增审批节点、分支优先级变更、默认分支保护、节点及分支删除、撤销恢复、未配置节点禁止保存、保存并刷新恢复。浏览器验证为交互检查，没有引入自动化 E2E 测试依赖。
